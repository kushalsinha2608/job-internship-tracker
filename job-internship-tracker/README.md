# Trackr — Job & Internship Tracker

A responsive browser-based application built with HTML, CSS and vanilla JavaScript.

## Features
- Add, edit and delete applications
- Track company, role, type, status, date, location, application URL and notes
- Search by company, role or location
- Filter by status and opportunity type
- Dashboard statistics
- Saves data in browser LocalStorage
- Responsive layout for desktop and mobile

## Run locally
1. Download and extract the project.
2. Open `index.html` in a modern browser.
3. Add your first application.

No server or package installation is required.

## Important
Data is stored only in the current browser using LocalStorage. It does not sync between devices or browsers. Clearing browser site data may remove saved applications.
